# caztmedia.com/jobb – Work Crush

`src/app/jobb/` är landningssidan för konceptet **Work Crush** (noindex). Själva appen – jobbsökare, rekryterare och admin – ligger i ett eget repo: **mansregren/workcrush** (https://workcrush.vercel.app). All historik, idélistan, besluten och vad som återstår finns i `docs/` i det repot.

Senaste ändringen av /jobb (13 okt 2026): ny hero "Find work worth falling for", sektionen "Mer än en jobbapp", fem nya telefonskärmar och sektionen "Ingen erfarenhet? Ingen fara.". Deploy: `vercel deploy --prod` från den här mappen (Vercel-projekt `vvs-sidor`).
